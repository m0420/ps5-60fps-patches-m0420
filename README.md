# PS5 60FPS Patches

This repository is just a place to save 60 FPS game patches for hacked PS5 consoles.

## Disclaimer

- No support is provided.
- Patches may be buggy or break after game updates.
- Use at your own risk.

## Releases

A GitHub Actions workflow automatically:

1. Detects JSON patch changes.
2. Builds a ZIP containing all JSON patch files.
3. Publishes a new release with automated notes that summarize new/updated games and cheats.
